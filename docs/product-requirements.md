# Product requirements

Northstar serves four primary actors: people hiring for their own organization, agencies hiring for clients, university placement teams, and people preparing for opportunities. The shared product primitive is an evidence record evaluated against explicit criteria and kept available for human review.

## Product principles

1. Criteria exist before scoring.
2. Scores remain traceable to evidence.
3. AI outputs are advisory.
4. Integrity signals create review work, never an automatic verdict.
5. Tenant boundaries are enforced server-side.
6. Candidate-facing experiences explain what is collected.

## Core journeys

- Employer: define role → weight requirements → add rounds → invite candidates → review evidence → move pipeline → record outcome.
- Staffing: add client → define commercial terms → run isolated hiring workflow → share safe report → record placement and fee.
- University: import cohort → configure season → measure readiness → publish drive → process applications → record offers and joining.
- Candidate: target role → practice → receive evidence-linked feedback → focus next attempt.

The full acceptance checklist remains in the user-provided goal and is mirrored incrementally in `docs/progress.md`.

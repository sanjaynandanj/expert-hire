# Permissions

Roles are platform admin, owner, admin, hiring manager, recruiter, interviewer, placement coordinator, viewer, student, and candidate.

Owners manage workspace configuration and members. Admins manage operational configuration without ownership transfer. Hiring managers can create roles, review candidates, and see agency commercial data. Recruiters operate assigned workflows but cannot change billing or security settings. Interviewers see assigned sessions and evidence. Placement coordinators run campus operations. Viewers are read-only. Students and candidates only access their own profiles, invitations, attempts, and reports made visible to them.

Every server mutation will map to an explicit permission. UI visibility is not authorization.
